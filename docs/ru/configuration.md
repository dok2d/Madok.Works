# Конфигурация

## Флаги запуска сервера

Сервер (`cmd/server/main.go`) принимает следующие флаги:

| Флаг          | Описание                                                        | По умолчанию      |
|---------------|----------------------------------------------------------------|-------------------|
| `-addr`       | Адрес и порт сервера                                            | `:8080`           |
| `-db`         | БД: путь к файлу SQLite **или** URL `postgres://…`/`postgresql://…` | `/data/kanban.db` |
| `-data-dir`   | Каталог для файловых артефактов (бэкапы); по умолчанию — каталог файла SQLite, а для Postgres `/data` | `` (авто)         |
| `-verbose`    | Подробное логирование                                          | `false`           |
| `-smtp-addr`  | Адрес приёма входящего SMTP (напр. `:25`); пусто — выключено   | `` (выключено)    |

### Внешняя БД (PostgreSQL)

Бэкенд выбирается значением `-db`: путь к файлу → SQLite (по умолчанию), URL
`postgres://user:pass@host:5432/dbname` → PostgreSQL. При работе с Postgres URL
обязательно задайте `-data-dir`, иначе каталогу бэкапов неоткуда взяться
(по умолчанию `/data`). Схема создаётся автоматически при старте. Формат
JSON-экспорта/бэкапа одинаков для обоих бэкендов, поэтому бэкап со SQLite можно
восстановить в Postgres и наоборот.

Пример:

```
kanban-server -db "postgres://kanban:secret@localhost:5432/kanban" -data-dir /var/lib/kanban
```

## Флаги kanban.sh

Для команд `run` и `deploy`:

| Флаг              | Описание                        | По умолчанию                    |
|-------------------|---------------------------------|---------------------------------|
| `--host <value>`  | FQDN или IP-адрес               | `kanban.local`                  |
| `--port <port>`   | Порт (nginx + контейнер)        | `443` (TLS) / `80` (HTTP)      |
| `--tls`           | Включить TLS (HTTPS)            | включён                        |
| `--no-tls`        | Только HTTP, без TLS            | —                               |
| `--cert <path>`   | Путь к TLS-сертификату          | `/etc/nginx/ssl/kanban.crt`    |
| `--key <path>`    | Путь к TLS-ключу                | `/etc/nginx/ssl/kanban.key`    |

## Переменные окружения

Альтернатива флагам — переменные окружения:

| Переменная         | Соответствует флагу |
|--------------------|---------------------|
| `KANBAN_HOST`      | `--host`            |
| `KANBAN_PORT`      | `--port`            |
| `KANBAN_TLS`       | `--tls` / `--no-tls`|
| `KANBAN_SSL_CERT`  | `--cert`            |
| `KANBAN_SSL_KEY`   | `--key`             |

Для исходящей почты (внешняя отправка с DKIM-подписью) есть отдельные переменные. То же самое настраивается в админке на вкладке «Почтовый сервер» (значения из админки имеют приоритет):

| Переменная             | Описание                                                  |
|------------------------|----------------------------------------------------------|
| `KANBAN_MAIL_DOMAIN`   | Домен отправки; задание включает исходящую почту         |
| `KANBAN_DKIM_SELECTOR` | DKIM-селектор (по умолчанию `default`)                    |
| `KANBAN_DKIM_KEY`      | Путь к приватному RSA-ключу в формате PEM для DKIM        |

## Настройки в интерфейсе

Все настройки собраны на **единой странице настроек**, которая открывается шестерёнкой внизу левой панели сервисов (app rail). Страница доступна всем пользователям, а её содержимое зависит от роли. Настройки разбиты на вкладки:

| Вкладка            | Кому доступна                              | Содержимое                                                            |
|--------------------|-------------------------------------------|----------------------------------------------------------------------|
| Общие              | Всем                                       | Тема, язык, размер шрифта, часовой пояс                               |
| Почта              | При включённой почте (кроме «только чтение»)| Правила распределения писем; управление ящиками/алиасами (админ)     |
| Интеграции         | Админам и тем, у кого настроен Telegram     | Telegram и SSO                                                        |
| Доска              | Только админам                             | Колонки, эпики, спринты, теги                                         |
| Пользователи       | Только админам                             | Управление пользователями                                            |
| Сервисы            | Только админам                             | Включение/выключение и порядок сервисов                              |
| Сайт               | Только админам                             | Название приложения (брендинг)                                        |
| Почтовый сервер    | Только админам                             | Домен отправки, DKIM-селектор и ключ, DNS TXT-запись, аудит          |
| Данные             | Только админам                             | Экспорт/импорт и бэкапы                                              |

### Тема оформления

8 тем на выбор: dark, light, ocean, forest, nord, dracula, solarized, spacedust. Выбор сохраняется в localStorage браузера.

### Язык

10 языков: русский, английский, китайский, испанский, французский, немецкий, португальский, японский, корейский, арабский.

### Размер шрифта

Настраиваемый размер шрифта (по умолчанию 18px).

### Часовой пояс

Часовой пояс задаётся на вкладке «Общие» и сохраняется на сервере:

```
POST /api/settings/timezone
{"timezone": "Europe/Moscow"}
```

### Название приложения (брендинг)

На вкладке «Сайт» (только админам) задаётся название приложения. Оно меняет заголовок вкладки браузера, название в шапке и на странице входа, а также используется в именах файлов бэкапов и в подписи ежедневного бэкапа в Telegram. По умолчанию — «Kanban».

```
POST /api/settings/app
{"name": "Acme Hub"}
```

### Сервисы

На вкладке «Сервисы» (только админам) каждый сервис экосистемы — включая саму канбан-доску — можно включить или выключить, а также изменить их порядок кнопками вверх/вниз. Порядок отражается на панели сервисов. Выключенный сервис блокируется и на сервере: его эндпоинты `/api` возвращают 403, а страницы — редирект, а не просто скрываются в интерфейсе.

### Почтовый сервер

На вкладке «Почтовый сервер» (только админам) настраиваются домен отправки, DKIM-селектор и приватный ключ, а также показывается публичная DNS TXT-запись для публикации. Эти значения дублируют переменные окружения `KANBAN_MAIL_DOMAIN` / `KANBAN_DKIM_SELECTOR` / `KANBAN_DKIM_KEY` и имеют над ними приоритет.

### Telegram-бот

Настройка на вкладке «Интеграции». Подробнее — [Telegram-бот](telegram.md).

## База данных

- SQLite с режимом WAL (Write-Ahead Logging) для параллельного доступа
- Поддержка внешних ключей
- Автоматические миграции при запуске
- Путь к БД задаётся флагом `-db`
