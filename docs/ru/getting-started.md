# Быстрый старт

## Требования

- **Podman** или **Docker**
- Для production-развёртывания: **nginx**, **systemd**

## Сборка и запуск

```bash
# Сборка контейнера
./kanban.sh build

# Запуск (по умолчанию http://127.0.0.1:8080)
./kanban.sh run
```

Откройте браузер по адресу `http://127.0.0.1:8080`.

## Первый запуск

При первом посещении отобразится **страница настройки администратора**. Введите логин и пароль — это будет главная учётная запись с полным доступом. На этой же странице есть:

- **Выбор языка/флага**, который задаёт язык интерфейса нового администратора и **язык по умолчанию** для всех, кто будет создан позже (каждый сможет потом сменить свой).
- Необязательный переключатель **«Использовать внешний PostgreSQL»** с полями подключения и кнопкой «Проверить подключение». Оставьте его выключенным для встроенной БД SQLite; включите, чтобы подключить инстанс к внешнему серверу PostgreSQL (см. [Конфигурацию](configuration.md)).

После создания администратора появляется одноразовый **визард первого запуска** с тремя вариантами:

- **Для себя** — канбан, календарь и вики включены; чат и почта выключены.
- **Командная работа** — выберите, какие сервисы включить.
- **Загрузить бэкап** — восстановить инстанс из файла бэкапа (через Импорт).

За визардом следует короткий, пропускаемый **гид-тур** по селектору проектов, панели сервисов, поиску и настройкам. (Админы могут запустить визард заново в разделе «Настройки → Сайт».)

### Проекты

В инстансе уже есть проект по умолчанию **«Общее»** (ключ `GEN`). Создавайте новые проекты через **селектор проектов в шапке** или в разделе **«Настройки → Доска → Проекты»**. У каждого проекта своя доска, вики и календари.

Оказавшись на доске, начните работу:

1. **Создайте колонки** — например, «To Do», «In Progress», «Done»
2. **Добавьте задачи** — нажмите «+» в нужной колонке
3. **Перетаскивайте карточки** между колонками для отслеживания прогресса

## Запуск на другом порту

```bash
./kanban.sh run --port 9090
```

## Команды управления

| Команда                | Описание                        |
|------------------------|---------------------------------|
| `./kanban.sh build`    | Сборка контейнера               |
| `./kanban.sh run`      | Запуск контейнера               |
| `./kanban.sh stop`     | Остановка                       |
| `./kanban.sh restart`  | Перезапуск                      |
| `./kanban.sh logs`     | Просмотр логов                  |
| `./kanban.sh backup`   | Резервная копия БД              |
| `./kanban.sh restore`  | Восстановление из бэкапа        |
| `./kanban.sh status`   | Статус контейнера               |
| `./kanban.sh deploy`   | Установка systemd + nginx       |
