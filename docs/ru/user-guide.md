# Руководство пользователя

Канбан-доска — основной сервис, но рядом с ней доступны и другие сервисы
экосистемы (wiki, чат, календарь, почта). Все они открываются из **панели
сервисов слева** (app rail). Подробное описание сервисов — в
[Сервисы экосистемы](ecosystem.md); ниже — краткие пользовательские сценарии.

## Проекты

Всё, с чем вы работаете — доска, пространства wiki и календари — находится внутри
**проекта**. **Активный проект** выбирается **селектором в шапке**; при
переключении меняются доска, wiki и календари, которые вы видите. Всегда есть
проект по умолчанию (с названием «Общее»), с которого можно начать.

### Создание проекта

Если вам разрешено создавать проекты, в селекторе есть пункт **«Новый проект»**.
Вы задаёте **название**, короткий **ключ** (заглавными, например `GEN`) и
**видимость**:

- **Открытый (все)** — проект видят все пользователи.
- **Закрытый (участники)** — проект видят только те, кто есть в списке участников.

### Роли и ключи задач

Внутри проекта у каждого участника есть **роль**:

- **Администратор** — управляет проектом, его участниками и настройками.
- **Редактор** — создаёт и редактирует задачи, страницы и события.
- **Чтение** — доступ только для просмотра.

Задачи нумеруются в пределах проекта и отображаются как **KEY-123** (ключ проекта
плюс порядковый номер), поэтому один и тот же номер может встречаться в разных
проектах без конфликтов.

### Модерация проектов

Администратор управляет всеми проектами в разделе **Настройки → Доска →
Проекты**: создаёт проекты, меняет видимость, добавляет и удаляет участников и их
роли.

## Доска

Основной экран — канбан-доска с колонками. Каждая колонка представляет этап работы (например, «To Do», «In Progress», «Done»). Задачи отображаются как карточки, которые можно перетаскивать между колонками.

### Управление колонками

- Администратор может создавать, переименовывать, переупорядочивать и удалять колонки
- Первую (Backlog) и последнюю (Done) колонки удалить нельзя
- Порядок колонок настраивается перетаскиванием

### Фильтрация

В шапке доски доступны фильтры:

- **⬡ kanban** — показать все задачи (без фильтрации)
- **Спринт** — фильтр по спринту (по умолчанию показывается самый старый активный)
- **Эпик** — фильтр по эпику

## Задачи

### Создание задачи

Нажмите «+» в нужной колонке. Укажите:

- **Название** — краткое описание задачи
- **Описание** — подробности в формате Markdown (поддержка подсветки синтаксиса)
- **Приоритет** — без приоритета, низкий, средний, высокий, критический
- **Дедлайн** — опциональная дата, отображается на карточке
- **Спринт** — привязка к спринту (или бэклог)
- **Эпик** — привязка к эпику
- **Теги** — произвольные метки
- **Исполнитель** — назначенный пользователь

Если администратор подключил LLM, в форме задачи также доступна
**✨ Сгенерировать** — она составит черновик **описания** и списка **TODO**,
который можно заменить или добавить к имеющемуся.

### Приоритеты

Приоритет отображается цветной полоской слева на карточке:

| Приоритет    | Цвет    |
|-------------|---------|
| Низкий      | синий   |
| Средний     | жёлтый  |
| Высокий     | оранжевый |
| Критический | красный |

### Markdown в описании

Описание задачи поддерживает Markdown:

- Заголовки, списки, ссылки, изображения
- Блоки кода с подсветкой синтаксиса (highlight.js)
- **TODO-списки** — интерактивные чекбоксы (`- [ ]` / `- [x]`), можно отмечать прямо в карточке

### Зависимости

Задачи могут иметь зависимости:

- **Зависит от** — задача не может быть выполнена, пока не закрыта другая
- **Блокирует** — эта задача блокирует выполнение другой

### Вложения

- **Изображения** — вставка через Ctrl+V (автоматическое сжатие до ~500 КБ)
- **Файлы** — PDF, текстовые файлы, архивы и другие форматы

## Спринты

Спринты помогают организовать работу по итерациям.

### Статусы спринта

1. **Планирование** — спринт создан, задачи добавляются
2. **Активный** — работа идёт
3. **Завершён** — спринт закрыт

### Завершение спринта

При завершении спринта незакрытые задачи автоматически переносятся в следующий активный спринт.

### Бэклог

Задачи без спринта попадают в бэклог — общий список задач, которые ждут планирования.

## Эпики

Эпики — это крупные инициативы, объединяющие несколько задач. Каждый эпик имеет:

- Название и описание
- Цветовую маркировку (отображается на карточках)
- Индикатор прогресса (доля завершённых задач)

## Теги

Теги — произвольные метки для категоризации задач. У задачи может быть несколько тегов. Теги доступны в поиске.

## Комментарии

- Вложенные комментарии с ответами (threading)
- Поддержка Markdown и подсветки синтаксиса
- **@упоминания** — при упоминании пользователь получает уведомление

## Поиск

Поиск доступен в шапке доски. Поддерживаются два режима:

- **Обычный текст** — поиск по вхождению подстроки
- **Regex** — поиск по регулярному выражению

Поиск работает по: названиям задач, описаниям, комментариям, тегам, эпикам.

### Глобальный поиск

Помимо поиска по доске есть **единый глобальный поиск** по всем сервисам.
Откройте его сочетанием **Ctrl/Cmd+K** или из поля поиска в шапке. В поле можно
выбрать область поиска: **все / канбан / wiki / чат / календарь / почта**; по
умолчанию ищется в текущем сервисе. Выбор результата открывает соответствующий
сервис.

Поиск **многословный**: если ввести несколько слов, в результат должно входить
**каждое** из них (то есть лишние слова сужают выборку, а не расширяют её).

## Уведомления

Уведомления приходят при:

- Назначении задачи на вас
- @упоминании в комментарии
- Обновлении задачи, на которую вы подписаны
- Новом комментарии к подписанной задаче

Можно подписаться на задачу через кнопку подписки в карточке. Уведомления доступны в приложении и через [Telegram-бот](telegram.md).

## Лента активности

Каждый пользователь имеет ленту активности с подробной историей изменений: создание задач, изменения статусов, комментарии и другие действия. Отображаются последние 100 записей.

## Настройки

Все настройки собраны на **единой странице**. Откройте её **шестерёнкой внизу
панели сервисов слева**. (Прежней шестерёнки в правом верхнем углу больше нет.)
Вкладки **сгруппированы** — верхнеуровневые группы (**Почта**, **Доска**,
**Сайт**) открывают вторичную панель подвкладок — а набор вкладок зависит от
вашей роли.

### Мои настройки

Ваши личные настройки отображения собраны на вкладке **«Мои настройки»**:

- **Тема оформления**, **язык интерфейса**, **размер шрифта** и **часовой пояс**.

Они индивидуальны — влияют только на ваш вид.

### Аккаунт

На вкладке **«Аккаунт»** — всё, что связано с вашим входом:

- **Смена пароля**.
- Привязка **Telegram** для уведомлений (см. [Telegram-бот](telegram.md)).
- **Двухфакторная аутентификация (2FA)** — см. ниже.

#### Двухфакторная аутентификация (2FA)

2FA добавляет одноразовый код из приложения-аутентификатора как второй шаг входа.
Чтобы включить, откройте **Аккаунт → Включить 2FA**, добавьте показанный секрет в
приложение-аутентификатор (или отсканируйте ссылку `otpauth`) и введите текущий
6-значный код для подтверждения. После этого вы получите набор **одноразовых
кодов восстановления** — сохраните их в надёжном месте на случай потери
приложения. Начиная **со следующего входа** система будет запрашивать текущий код
после пароля. Отключить 2FA можно на той же вкладке.

### Настройки почты

- **Почта** — правила распределения входящих писем по папкам (см. раздел
  [Почта](#почта)).

### Настройки администратора

Администратору дополнительно доступны вкладки (в группах **Доска** и **Сайт**):

- **Доска → Проекты** — создание и модерация [проектов](#проекты) и их
  участников.
- **Сайт** — **«Название приложения»** (заголовок вкладки браузера, название в
  шапке и на странице входа, а также имена файлов бэкапов) и **язык по
  умолчанию** для новых пользователей.
- **Сервисы** — включение и выключение сервисов (включая саму канбан-доску) и
  изменение их порядка в панели сервисов.

Подробнее об управлении сервисами — в [Сервисы экосистемы](ecosystem.md).

## Язык

Каждый пользователь выбирает **свой язык интерфейса** на вкладке
[**«Мои настройки»**](#мои-настройки); он влияет только на ваш вид.

**Язык по умолчанию для новых пользователей** задаётся при первом создании
инстанса: на экране регистрации есть **выбор флага**, который автоматически
определяется по браузеру (а если ни один из предложенных языков не подходит —
используется русский). Администратор может позже сменить этот язык по умолчанию в
**Настройки → Сайт**.

## Wiki

Документация в духе Confluence. Пространство выбирается **в шапке** (выпадающий
список), дерево страниц — в сайдбаре.

Страницы редактируются в **редакторе Markdown** с живым предпросмотром и панелью
форматирования: заголовки, жирный / курсив / зачёркнутый, инлайн-код и блок кода,
списки, цитата, ссылка, вставка картинки, таблица (размер выбирается мышью),
выноски (callout). Отдельного визуального (WYSIWYG) режима нет.

У каждой страницы есть **история ревизий** — можно просмотреть и восстановить
прежнюю версию. Страницы также поддерживают **комментарии**, **реакции**,
переиспользуемые **шаблоны** и встроенные **диаграммы**. Поиск по wiki — через
общий [глобальный поиск](#глобальный-поиск).

### Ссылки на разделы (якоря)

У каждого заголовка на странице есть постоянный **якорь**. Наведите курсор на
заголовок и нажмите появившийся значок **#**, чтобы скопировать прямую ссылку на
этот раздел; открытие адреса вида `/wiki/page#раздел` сразу прокручивает к этому
заголовку. Вставьте в страницу токен **`[[toc]]`**, чтобы получить автоматическое
оглавление по её заголовкам.

Подробнее — в [Сервисы экосистемы](ecosystem.md).

## Чат

Обмен сообщениями в стиле Telegram: **публичные каналы**, **приватные группы** и
**личные сообщения** (в разделе ЛС все пользователи сразу доступны как контакты).

- Сообщения отображаются **пузырями** с **аватарами**.
- **Ответы** (цитирование) с переходом к исходному сообщению — **двойной щелчок
  по сообщению** для быстрого ответа.
- **Реакции эмодзи**.
- **Закрепление сообщений** — закреплённое показывается в баре вверху.
- Меню действий над сообщением — кнопка **«⋯»** (ответить, реакция, закрепить,
  изменить, удалить).
- Индикатор «**печатает…**» и **галочки прочтения** в личных сообщениях.
- **Вложения** (файлы и картинки) и **системные сообщения** (создание чата,
  вступление/выход, переименование).
- Список чатов сортируется по последнему сообщению.

### Публичные каналы и приватные группы

При создании чата вы выбираете его тип:

- **Новый канал** — публичный канал, который видят и читают все пользователи.
- **Новая группа** — приватная группа; участники добавляются через **выбор
  участников**, и видят её только они.

### Каналы только для чтения

Канал можно сделать **только для чтения** — тогда большинство участников могут
только читать. Писать могут только назначенные **избранные**, **создатель**
канала и **администраторы**; остальным вместо поля ввода показывается пометка
«только чтение».

### Заглушение и звук уведомлений

В шапке чата можно **заглушить** отдельный канал на **1 час**, **8 часов** или
**навсегда** (и снова включить уведомления), а также переключить **глобальный
звук уведомлений** о новых сообщениях.

Поиск по чату — через общий [глобальный поиск](#глобальный-поиск). Подробнее — в
[Сервисы экосистемы](ecosystem.md).

## Звонки

Голосовые и видеозвонки идут напрямую между участниками (WebRTC). Начните звонок
кнопками **📞 (голос)** или **📹 (видео)** в **шапке чата** любого канала, группы
или личной переписки.

- Собеседник видит **входящий вызов** и может **Принять** или **Отклонить**.
- В звонке доступны **выключение микрофона**, переключение **камеры** и
  **завершение** вызова.
- Можно **добавить любого пользователя** к уже идущему звонку.

> Звонки работают «из коробки» в пределах одной сети. Для надёжных звонков
> **между разными сетями** (NAT/файрволы) администратору нужно настроить
> **TURN-сервер** в настройках.

## Календарь

Вид (месяц / неделя / день / повестка) и список календарей выбираются **в шапке**.
Поддерживаются **повторяющиеся события**, **настраиваемые напоминания** и
read-only наложение **дедлайнов задач и спринтов** с доски.

**Навигация по периодам:**

- В месячном и недельном виде слева показан **номер недели** (по стандарту ISO).
- **Колёсиком мыши** можно листать периоды: на шаг, соответствующий виду (месяц /
  неделя / день). В режиме «Повестка» прокрутка не листает.
- Клик по **году** в заголовке открывает мини-календарь: сначала выбор года, затем
  выбор месяца — быстрый переход к нужной дате.

### Подключение Google-календаря (ICS)

Можно подписаться на внешний календарь только для чтения:

1. В Google Календаре откройте **Настройки календаря → «Секретный адрес в формате
   iCal»** и скопируйте адрес.
2. В приложении в выпадающем списке **«Календари»** выберите **«+ Google Календарь
   (ICS)»** и вставьте этот секретный адрес.

События появятся наложением **только для чтения** и будут синхронизироваться
автоматически. Подписка **приватная** — видна только вам.

Подробнее — в [Сервисы экосистемы](ecosystem.md).

## Почта

Папки и кнопка **«Написать»** находятся **в шапке**. Интерфейс **двухпанельный**:
список писем слева, выбранное письмо справа; границу между панелями можно двигать
мышью.

- **Правила распределения** входящих писем настраиваются в
  [настройках](#личные-настройки) на вкладке «Почта».
- Есть папка **«Спам»** (антиспам-эвристики).
- Поиск по почте — через общий [глобальный поиск](#глобальный-поиск).

Подробнее — в [Сервисы экосистемы](ecosystem.md).
