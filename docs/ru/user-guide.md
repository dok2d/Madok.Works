# Руководство пользователя

Канбан-доска — основной сервис, но рядом с ней доступны и другие сервисы
экосистемы (wiki, чат, календарь, почта). Все они открываются из **панели
сервисов слева** (app rail). Подробное описание сервисов — в
[Сервисы экосистемы](ecosystem.md); ниже — краткие пользовательские сценарии.

## Доска

Основной экран — канбан-доска с колонками. Каждая колонка представляет этап работы (например, «To Do», «In Progress», «Done»). Задачи отображаются как карточки, которые можно перетаскивать между колонками.

### Управление колонками

- Администратор может создавать, переименовывать, переупорядочивать и удалять колонки
- Первую (Backlog) и последнюю (Done) колонки удалить нельзя
- Порядок колонок настраивается перетаскиванием

### Фильтрация

В шапке доски доступны фильтры:

- **⬡ kanban** — показать все задачи (без фильтрации)
- **Спринт** — фильтр по спринту (по умолчанию показывается самый старый активный)
- **Эпик** — фильтр по эпику

## Задачи

### Создание задачи

Нажмите «+» в нужной колонке. Укажите:

- **Название** — краткое описание задачи
- **Описание** — подробности в формате Markdown (поддержка подсветки синтаксиса)
- **Приоритет** — без приоритета, низкий, средний, высокий, критический
- **Дедлайн** — опциональная дата, отображается на карточке
- **Спринт** — привязка к спринту (или бэклог)
- **Эпик** — привязка к эпику
- **Теги** — произвольные метки
- **Исполнитель** — назначенный пользователь

### Приоритеты

Приоритет отображается цветной полоской слева на карточке:

| Приоритет    | Цвет    |
|-------------|---------|
| Низкий      | синий   |
| Средний     | жёлтый  |
| Высокий     | оранжевый |
| Критический | красный |

### Markdown в описании

Описание задачи поддерживает Markdown:

- Заголовки, списки, ссылки, изображения
- Блоки кода с подсветкой синтаксиса (highlight.js)
- **TODO-списки** — интерактивные чекбоксы (`- [ ]` / `- [x]`), можно отмечать прямо в карточке

### Зависимости

Задачи могут иметь зависимости:

- **Зависит от** — задача не может быть выполнена, пока не закрыта другая
- **Блокирует** — эта задача блокирует выполнение другой

### Вложения

- **Изображения** — вставка через Ctrl+V (автоматическое сжатие до ~500 КБ)
- **Файлы** — PDF, текстовые файлы, архивы и другие форматы

## Спринты

Спринты помогают организовать работу по итерациям.

### Статусы спринта

1. **Планирование** — спринт создан, задачи добавляются
2. **Активный** — работа идёт
3. **Завершён** — спринт закрыт

### Завершение спринта

При завершении спринта незакрытые задачи автоматически переносятся в следующий активный спринт.

### Бэклог

Задачи без спринта попадают в бэклог — общий список задач, которые ждут планирования.

## Эпики

Эпики — это крупные инициативы, объединяющие несколько задач. Каждый эпик имеет:

- Название и описание
- Цветовую маркировку (отображается на карточках)
- Индикатор прогресса (доля завершённых задач)

## Теги

Теги — произвольные метки для категоризации задач. У задачи может быть несколько тегов. Теги доступны в поиске.

## Комментарии

- Вложенные комментарии с ответами (threading)
- Поддержка Markdown и подсветки синтаксиса
- **@упоминания** — при упоминании пользователь получает уведомление

## Поиск

Поиск доступен в шапке доски. Поддерживаются два режима:

- **Обычный текст** — поиск по вхождению подстроки
- **Regex** — поиск по регулярному выражению

Поиск работает по: названиям задач, описаниям, комментариям, тегам, эпикам.

### Глобальный поиск

Помимо поиска по доске есть **единый глобальный поиск** по всем сервисам.
Откройте его сочетанием **Ctrl/Cmd+K** или из поля поиска в шапке. В поле можно
выбрать область поиска: **все / канбан / wiki / чат / календарь / почта**; по
умолчанию ищется в текущем сервисе. Выбор результата открывает соответствующий
сервис.

## Уведомления

Уведомления приходят при:

- Назначении задачи на вас
- @упоминании в комментарии
- Обновлении задачи, на которую вы подписаны
- Новом комментарии к подписанной задаче

Можно подписаться на задачу через кнопку подписки в карточке. Уведомления доступны в приложении и через [Telegram-бот](telegram.md).

## Лента активности

Каждый пользователь имеет ленту активности с подробной историей изменений: создание задач, изменения статусов, комментарии и другие действия. Отображаются последние 100 записей.

## Настройки

Все настройки собраны на **единой странице**. Откройте её **шестерёнкой внизу
панели сервисов слева**. (Прежней шестерёнки в правом верхнем углу больше нет.)
Набор вкладок зависит от вашей роли.

### Личные настройки

- **Общие** — тема оформления, язык интерфейса, размер шрифта, часовой пояс.
- **Почта** — правила распределения входящих писем по папкам (см. раздел
  [Почта](#почта)).
- **Интеграции** — привязка **Telegram** для уведомлений (см.
  [Telegram-бот](telegram.md)).

### Настройки администратора

Администратору дополнительно доступны вкладки:

- **Сайт** — **«Название приложения»**. Меняет заголовок вкладки браузера,
  название в шапке и на странице входа, а также используется в именах файлов
  бэкапов.
- **Сервисы** — включение и выключение сервисов (включая саму канбан-доску) и
  изменение их порядка в панели сервисов.

Подробнее об управлении сервисами — в [Сервисы экосистемы](ecosystem.md).

## Wiki

Документация в духе Confluence. Пространство выбирается **в шапке** (выпадающий
список), дерево страниц — в сайдбаре.

Страницы редактируются в **редакторе Markdown** с живым предпросмотром и панелью
форматирования: заголовки, жирный / курсив / зачёркнутый, инлайн-код и блок кода,
списки, цитата, ссылка, вставка картинки, таблица (размер выбирается мышью),
выноски (callout). Отдельного визуального (WYSIWYG) режима нет.

У каждой страницы есть **история ревизий** — можно просмотреть и восстановить
прежнюю версию. Поиск по wiki — через общий [глобальный поиск](#глобальный-поиск).

Подробнее — в [Сервисы экосистемы](ecosystem.md).

## Чат

Обмен сообщениями в стиле Telegram: **каналы**, **группы** и **личные сообщения**
(в разделе ЛС все пользователи сразу доступны как контакты).

- Сообщения отображаются **пузырями** с **аватарами**.
- **Ответы** (цитирование) с переходом к исходному сообщению.
- **Реакции эмодзи**.
- **Закрепление сообщений** — закреплённое показывается в баре вверху.
- Меню действий над сообщением — кнопка **«⋯»** (ответить, реакция, закрепить,
  изменить, удалить).
- Индикатор «**печатает…**» и **галочки прочтения** в личных сообщениях.
- **Вложения** (файлы и картинки) и **системные сообщения** (создание чата,
  вступление/выход, переименование).
- Список чатов сортируется по последнему сообщению.

Поиск по чату — через общий [глобальный поиск](#глобальный-поиск). Подробнее — в
[Сервисы экосистемы](ecosystem.md).

## Календарь

Вид (месяц / неделя / день / повестка) и список календарей выбираются **в шапке**.
Поддерживаются **повторяющиеся события**, **настраиваемые напоминания** и
read-only наложение **дедлайнов задач и спринтов** с доски.

### Подключение Google-календаря (ICS)

Можно подписаться на внешний календарь только для чтения:

1. В Google Календаре откройте **Настройки календаря → «Секретный адрес в формате
   iCal»** и скопируйте адрес.
2. В приложении в выпадающем списке **«Календари»** выберите **«+ Google Календарь
   (ICS)»** и вставьте этот секретный адрес.

События появятся наложением **только для чтения** и будут синхронизироваться
автоматически. Подписка **приватная** — видна только вам.

Подробнее — в [Сервисы экосистемы](ecosystem.md).

## Почта

Папки и кнопка **«Написать»** находятся **в шапке**. Интерфейс **двухпанельный**:
список писем слева, выбранное письмо справа; границу между панелями можно двигать
мышью.

- **Правила распределения** входящих писем настраиваются в
  [настройках](#личные-настройки) на вкладке «Почта».
- Есть папка **«Спам»** (антиспам-эвристики).
- Поиск по почте — через общий [глобальный поиск](#глобальный-поиск).

Подробнее — в [Сервисы экосистемы](ecosystem.md).
