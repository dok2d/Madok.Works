# Сервисы экосистемы

Канбан-доска — один из нескольких сервисов self-hosted экосистемы **Madok.Works**
(компактный знак **MW**). Все сервисы используют общую аутентификацию, роли,
уведомления, глобальный поиск, темы и локализацию, а доступны через **app rail**
(панель слева/снизу).

Администратор включает и выключает каждый сервис (включая **саму канбан-доску**) и
меняет их порядок в **Настройки → Сервисы** — любой сервис можно отключить.
Выключенный сервис скрыт из интерфейса и недоступен на сервере (его API возвращает
`403`/`404`).

Madok.Works из коробки работает на встроенной базе данных; для крупных развёртываний
доступен опциональный бэкенд **PostgreSQL** (`-db postgres://…`).

## Проекты

**Проект** — это контейнер верхнего уровня, который ограничивает **канбан-доску**,
**wiki** и **календари**, относящиеся к нему. Из коробки есть проект по умолчанию
**«Общее»**, а администратор может создавать новые.

- **Видимость:** каждый проект — `open` (все пользователи) или `restricted` (только
  участники).
- **Роли** внутри проекта: `admin` / `editor` / `viewer`.
- **Ключи задач по проекту:** задачи нумеруются как `KEY-123` с использованием ключа
  проекта, поэтому номера остаются уникальными и осмысленными во всех проектах. Теги
  тоже свои на проект.
- **Селектор проекта в шапке** переключает активный проект; показанные канбан-доска и
  пространства wiki зависят от выбранного проекта.
- **Календарь — сквозной** (cross-project): он охватывает все доступные вам проекты,
  а не привязан к одному.
- Создание и модерация проектов — в **Настройки → Доска → Проекты**.

## Wiki

Документация в духе Confluence.

- **Пространства** (spaces) с ролевой моделью `admin` / `editor` / `viewer` и
  видимостью `open` (все пользователи) или `restricted` (только участники).
- **Выбор пространства — в шапке приложения** (выпадающий список в стиле фильтра
  спринтов канбана). **Дерево страниц** — в сайдбаре; перемещение страниц из меню
  (вверх/вниз, вложить/выложить).
- **Редактор только Markdown**: textarea с живым предпросмотром и панель
  форматирования — заголовки, жирный / курсив / зачёркнутый, инлайн-код, списки,
  цитата, блок кода, ссылка, вставка картинки (загрузка), таблица (выбор размера
  мышью → markdown-таблица), выноски (callout).
- **История ревизий** на каждой странице — просмотр и восстановление. Хранится
  и markdown-исходник, и санитайзенный HTML.
- **Автоякоря у заголовков:** каждый заголовок получает стабильный якорь; при
  наведении на заголовок появляется **#**, по клику копируется прямая ссылка на этот
  раздел.
- Отдельного поиска по wiki нет — используется общий **глобальный поиск**.

## Чат

Обмен сообщениями в реальном времени, приближённый к Telegram.

- **Публичные каналы**, приватные **группы** и **личные сообщения**. В разделе ЛС
  сразу списком показаны все остальные пользователи как контакты; клик создаёт
  диалог.
- **Создание приватных групп** с **выбором участников** — при создании группы можно
  указать ровно тех, кто в неё войдёт.
- **Каналы только для чтения:** канал можно сделать read-only, чтобы писать могли
  только его **назначенные авторы** (а также создатель и админы), а остальные читали.
- **Уведомления:** глобальное **переключение звука уведомлений**, а также
  **отключение звука по каналу** на **1 час / 8 часов / навсегда**.
- **Сообщения**: текст и вложения (файлы и инлайн-картинки), редактирование,
  удаление, **@-упоминания** (уведомления in-app + Telegram).
- **Ответы** (цитирование) с переходом к исходному сообщению.
- **Реакции эмодзи** (положительные и отрицательные), переключаются, видна своя
  реакция.
- **Закреплённые сообщения**: бар закреплённого вверху (несколько, листание,
  переход), пин/анпин (в публичных каналах — менеджеры, в группах/ЛС — любой
  участник).
- Действия над сообщением — в выпадающем меню (⋯): ответить / реакция / закрепить /
  изменить / удалить.
- Вид «как в Telegram»: пузыри (свои справа акцентом, чужие слева), аватары-инициалы,
  имя автора в группах/каналах, время в углу пузыря, разделители дат, группировка
  подряд идущих сообщений.
- **Галочки прочтения** в ЛС (✓ отправлено / ✓✓ прочитано собеседником).
- Индикатор «**печатает…**».
- **Системные сообщения** (создан чат, вступил / вышел, переименование).
- **Список чатов**: аватар, имя, превью последнего сообщения, время, бейдж
  непрочитанного; сортировка по дате последнего сообщения.
- Живые обновления через Server-Sent Events; бейджи непрочитанного на app rail.
  Отдельного поиска по чату нет — общий **глобальный поиск**.

### Звонки

Голосовые и видеозвонки работают в браузере поверх **WebRTC**.

- **Звонки 1:1 и в небольших группах** по топологии mesh (каждый участник соединяется
  напрямую с остальными).
- **UI входящего звонка** (звонок) и элементы управления в звонке — **микрофон** и
  включение/выключение **камеры**.
- **Приглашение любого участника по ходу звонка** к уже идущему звонку.
- Сигнализация идёт по существующему каналу SSE + POST. **STUN**-сервер встроен; для
  ретрансляции через более строгие NAT/файрволы можно настроить опциональный
  **self-hosted TURN**-сервер (например, coturn).

## Календарь

- **Личные** и **общие** календари с цветами.
- **Выбор вида** (месяц / неделя / день / повестка) и **список календарей**
  (видимость чекбоксами) — в **шапке** (выпадающие списки в стиле канбана);
  отдельный сайдбар календаря убран.
- **Навигация:** номер недели (ISO) в месячном и недельном виде; листание
  периодов **колёсиком мыши** (кроме «Повестки»); клик по году открывает
  мини-календарь для выбора года, затем месяца.
- **Повторяющиеся события** (RRULE: `FREQ` ежедневно/еженедельно/ежемесячно/
  ежегодно, `INTERVAL`, `COUNT`, `UNTIL`).
- **Настраиваемые напоминания** (Telegram / in-app / оба), в том числе для
  повторяющихся событий.
- Read-only слой **дедлайнов задач и спринтов** с доски; переключается, клик
  открывает элемент доски.
- **Подписки на внешние календари (ICS/iCal)**, read-only. Каждый пользователь
  добавляет «секретный адрес в формате iCal» своего календаря (например, Google
  Calendar) в выпадающем списке «Календари» → **«+ Google Календарь (ICS)»**.
  События показываются наложением своим цветом только для чтения; сервер
  периодически (каждые ~15 минут) синхронизирует подписки. Подписки приватные
  (видны только владельцу). Есть защита от SSRF, таймаут и лимит размера ответа.
  Двусторонней синхронизации/OAuth нет — только импорт по ICS.
- Время хранится в UTC и показывается в часовом поясе пользователя.

## Почта

Внутренняя почта работает «из коробки»; внешний SMTP — опционально.

- **Внутренняя почта** между пользователями: папки (Входящие / Отправленные /
  Черновики / Спам / Корзина + пользовательские), треды, вложения, бейдж
  непрочитанного, метка / корзина, ответ с цитатой.
- **Папки — в шапке** как выпадающий список, сразу после — кнопка **«Написать»**
  (стиль канбана). Отдельный поиск по почте убран — общий **глобальный поиск**.
- **Двухпанельный интерфейс** на широком экране: список писем слева, выбранное
  письмо справа; границу можно двигать мышью (ширина запоминается в браузере).
- **Правила распределения писем** (фильтры) — в **Настройках, вкладка «Почта»**.
- **Антиспам**: эвристики + проверка DKIM входящих → папка «Спам». **Аудит**
  почтовых событий (для админа), управление **ящиками/алиасами** (админ),
  настройки почтового сервера: домен, DKIM-селектор и приватный ключ (админ;
  вкладки «Почта» / «Почтовый сервер»).
- **Входящий SMTP** (опц.): запустить слушатель флагом `-smtp-addr` (например `:25`).
  Полученные письма разбираются (MIME) и кладутся во «Входящие» соответствующего
  пользователя (local-part адреса сопоставляется с логином).
- **Исходящий SMTP** (опц.): домен + DKIM (через env или настройки в админке);
  адресаты, указанные полным email, доставляются на их MX-серверы, с DKIM-подписью
  при наличии ключа.
- **Защита**: rate-limit входящего, SSRF-guard исходящего, защита от CRLF/
  заголовочных инъекций, лимиты размеров.

### Настройка почты

| Параметр | Где | Назначение |
|----------|-----|-----------|
| `-smtp-addr` | флаг CLI | Адрес приёма входящего SMTP (пусто = приём выключен) |
| `KANBAN_MAIL_DOMAIN` | env | Домен отправки; включает исходящую почту |
| `KANBAN_DKIM_SELECTOR` | env | DKIM-селектор (по умолчанию `default`) |
| `KANBAN_DKIM_KEY` | env | Путь к PEM RSA-ключу для DKIM-подписи |

Те же параметры исходящей почты (домен, DKIM-селектор и ключ) можно задать в
админке во вкладке «Почтовый сервер» — они переопределяют переменные окружения.

> **Про развёртывание.** Доставка внешней почты требует реальной инфраструктуры:
> публичный IP, DNS-записи (MX, SPF, DKIM, DMARC) и TLS. Это настраивается на уровне
> сети/DNS, вне приложения. Внутренней почте и разбору входящих это не нужно.

## Глобальный поиск

Нажмите **Ctrl/Cmd+K** (или используйте поле поиска в шапке), чтобы искать сразу по
всем сервисам. В поле есть выбор сервиса: **все / канбан / wiki / чат / календарь /
почта**; выбор результата открывает соответствующий сервис.
