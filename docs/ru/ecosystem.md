# Сервисы экосистемы

Канбан-доска — один из нескольких сервисов небольшой self-hosted экосистемы. Все
сервисы используют общую аутентификацию, роли, уведомления, глобальный поиск, темы
и локализацию, а доступны через **app rail** (панель слева/снизу).

Администратор включает и выключает каждый сервис в **Настройки → Сервисы**.
Выключенный сервис скрыт из интерфейса, а его API возвращает `404`.

## Wiki

Документация в духе Confluence.

- **Пространства** с вложенным **деревом страниц**; перемещение страниц из меню
  (вверх/вниз, вложить/выложить).
- **WYSIWYG-редактор** (заголовки, списки, блоки кода, таблицы, выноски, картинки).
- **История ревизий** на каждой странице — просмотр и восстановление.
- **Ролевая модель пространства**: `admin` / `editor` / `viewer`, плюс видимость
  `open` (все пользователи) или `restricted` (только участники).
- Полнотекстовый **поиск** по доступным пространствам.

## Чат

Обмен сообщениями в реальном времени.

- **Публичные каналы**, приватные **группы** и **личные сообщения**.
- Живые обновления через Server-Sent Events; бейджи непрочитанного на app rail.
- **@-упоминания** создают уведомления in-app и в Telegram.
- **Редактирование / удаление** сообщений, подгрузка истории, поиск по доступным каналам.

## Календарь

- **Личные** и **общие** календари с цветами.
- Виды **месяц / неделя / день / повестка**; перенос события на другой день
  перетаскиванием.
- **Повторяющиеся события** (RRULE: `FREQ` ежедневно/еженедельно/ежемесячно/ежегодно,
  `INTERVAL`, `COUNT`, `UNTIL`).
- **Напоминания** (примерно за 15 минут) через уведомления in-app + Telegram.
- Read-only слой **дедлайнов задач и спринтов** с доски; клик открывает элемент доски.
- Время хранится в UTC и показывается в часовом поясе пользователя.

## Почта

Внутренняя почта работает «из коробки»; внешний SMTP — опционально.

- **Внутренняя почта** между пользователями: папки (Входящие/Отправленные/Черновики/
  Корзина), треды, вложения, поиск, бейдж непрочитанного, метка/корзина, ответ с цитатой.
- **Входящий SMTP** (опц.): запустить слушатель флагом `-smtp-addr` (например `:25`).
  Полученные письма разбираются (MIME) и кладутся во «Входящие» соответствующего
  пользователя (local-part адреса сопоставляется с логином).
- **Исходящий SMTP** (опц.): при настройке адресаты, указанные полным email,
  доставляются на их MX-серверы, с DKIM-подписью при наличии ключа.

### Настройка почты

| Параметр | Где | Назначение |
|----------|-----|-----------|
| `-smtp-addr` | флаг CLI | Адрес приёма входящего SMTP (пусто = приём выключен) |
| `KANBAN_MAIL_DOMAIN` | env | Домен отправки; включает исходящую почту |
| `KANBAN_DKIM_SELECTOR` | env | DKIM-селектор (по умолчанию `default`) |
| `KANBAN_DKIM_KEY` | env | Путь к PEM RSA-ключу для DKIM-подписи |

> **Про развёртывание.** Доставка внешней почты требует реальной инфраструктуры:
> публичный IP, DNS-записи (MX, SPF, DKIM, DMARC) и TLS. Это настраивается на уровне
> сети/DNS, вне приложения. Внутренней почте и разбору входящих это не нужно.

## Глобальный поиск

Нажмите **Ctrl/Cmd+K** (или кнопку 🔍 в шапке), чтобы искать сразу по доске, wiki,
чату и почте; выбор результата открывает соответствующий сервис.
